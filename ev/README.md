# Test EV

[Josev](https://github.com/SwitchEV/iso15118) EV simulator, unmodified,
configured for ISO 15118-2 AC with EIM and TLS 1.2. It trusts only the test
V2G root generated by the test layer at first start.

Josev is a third-party dependency under its own licence; this directory holds
only configuration and start scripts.

## Requirements

TK-1, TK-3, TK-5, TK-8, TK-12 — see
[`../docs/requirements.md`](../docs/requirements.md).
